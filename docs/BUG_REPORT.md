Use only a maintainer-verified issue destination. A public issue route is not designated by this staged package. Vulnerabilities follow [SECURITY](../SECURITY.md).

- Expected result and observed result, each stated plainly.
- Minimal repeatable steps with invented labels.
- Application release, candidate SHA-256 and source commit when known.
- Browser family/version; hub OS, architecture and Node version; collector/source version if relevant.
- Live or Replay; first install or update; relevant source age and fixed error/status code.
- A manually reviewed diagnostic attachment only if needed.

Remove prompts, code, command arguments, raw logs, private paths/URLs, account identifiers, credentials and project names. Do not upload full databases or configurations. Previewing a local support file does not authorize sending it. The local doctor is a bounded diagnostic aid, not browser or installation acceptance.
