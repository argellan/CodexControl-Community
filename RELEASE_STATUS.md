# CodexControl V1 Fleet Observer

Local preparation candidate: CodexControl 1.2.0 rc3 from canonical base `8a3c532e1b4fb323649b00b07fa3b5a4e14cb55d`, with integrated manuals/atlas, original synthetic demo media, supplied ARGELLAN artwork, corrected packaging mappings, narrow media path admission and the VM test-harness repair. The included optional historical analytics source remains disabled until separately configured. Exact hashes and checks are supplied with the candidate. Final product/version policy, target qualification, deployment and public publication remain separate Owner decisions.

Version 1.2.0 is a self-hosted, read-only observation release for a private trusted network. It adds bounded inspectable Ribbon lanes, independent Flow/Ribbon zoom, investigation context and evidence references, readable reviewed Handoff previews, and improved Settings navigation. It retains optional scoped GitHub metadata, conditional recovery, an on-demand ARGELLAN dialog and exact-receipt archives, while preserving the 1.0.1 fixes. The retained maintenance behavior refuses credential delivery from legacy collectors that lack a pinned hub identity, checks TLS private-key file access, corrects scoped event recovery metadata, and preserves unarchived event rows beyond hot-cache targets. The maintainer repository remains private during this launch. A source tag does not imply a signed installer, public registry package, container image or internet-hosted service.

This local candidate also adds bounded offline diagnostics and reviewed manual export. Automatic sharing is off by default and supports only an explicitly configured loopback synthetic test recipient with separate browser-session and administrator consent. Real-user reporting and hosted receiver deployment remain disabled. See docs/design/DIAGNOSTICS_PRIVACY.md for the exact fields, retention and limitations.

The release includes deliberately enrolled machine observation; worker/subagent inspection; an event-driven Flow map and Ribbon; synchronized timeline and bounded replay/recovery; typed numeric usage and optional account observations; usage preservation/archiving; scoped dashboard accounts and personal profiles; grouped Settings; local reviewed usage exports; and a review-required Obsidian handoff.

Usage observations have a verified off-host archive path. Event observations do not yet have that path: they remain on the hub's local disk beyond hot-cache targets until a separate immutable archive and receipt-gated eviction are implemented. Earlier builds could expire event rows, so a reported retention floor is a real historical gap, not complete history.

Observation routes require captured relationships. Recorded results do not establish independent acceptance. No control launches, stops, steers, approves or resumes Codex work. Prompts, arguments, raw output, provider credentials and private reasoning text remain excluded.

Native desktop voice state, automatic Cloud discovery, execution controls, SSO/MFA/email recovery, Android/TV applications, direct Timescale queries and automatic provider Checks access without a suitable GitHub App are not supported V1 workflows. The Obsidian packet carries bounded reviewed observation metadata and an optional user summary, not full conversation or artifact contents.

Use the packaged INSTALL, UPDATE, SUPPORT_MATRIX and RELEASE_PREPARATION_VALIDATION documents. The illustrated user guide and interface atlas are available from Profile and public/assets. Source code is MIT; included third-party notices and the separate ARGELLAN trademark policy remain applicable. Manifest checksums establish integrity, not publisher identity or independent security certification.
